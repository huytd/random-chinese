# Random Chinese

A Chrome extension for learning Chinese while you browse. On English pages it swaps a random share of words for their Chinese translation at your HSK level. Click a swapped word to see its pinyin and meanings and hear how it's pronounced.

> Today I want to 告诉 you about my 朋友. We like to 吃 rice and 喝 茶 in the morning.

## Install

1. Open `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and pick this folder.
3. Pin the extension and open any English page.

## Settings (toolbar popup)

| Setting | What it does |
|---|---|
| On/off | Turns the extension on or off everywhere. The site switch pauses it for the current site only. |
| HSK 3.0 / HSK 2.0 | Which syllabus to use. HSK 3.0 (2021) has levels 1–6 plus 7–9; HSK 2.0 has levels 1–6. |
| Level | Uses words up to and including this level. With **Only words new at this level**, it uses only the words that level introduces. |
| Replace | The percentage of translatable words that get replaced (1–100%, default 15%). |
| 简体 / 繁體 | Simplified or traditional characters. |
| Show pinyin above words | Shows pinyin as ruby text over each replaced word. |
| Shuffle | Picks a new random set of words on the current page. |

Settings sync through your Chrome profile and apply right away to open tabs.

## Word card

Clicking a replaced word (it won't follow the link if the word sits inside one) opens a card with:

- the characters, plus the other script when it differs (书 / 書)
- pinyin with tone marks and a 🔊 button that reads the word aloud (it uses Chrome's `chrome.tts` Chinese voice, falling back to the Web Speech API)
- the HSK level and up to three meanings
- the original English word, with a **Show English** button that puts it back

Press Esc or click anywhere else to close the card.

## How it works

- **Part of speech** – each paragraph goes through [compromise](https://github.com/spencermountain/compromise) (MIT, `vendor/compromise.js`), an English tagger that runs in the page. It tells the verb in "**Building** apps" from the noun in "the **building**", and it gives each word's base form, so irregular forms like bought, children and went work too. It also flags names and brands (Bill, Apple), phrasal verbs ("gave **up**"), possessives, comparatives and dates, and works out what "they" refers to.
- **Dictionary** – `src/dict.js` is generated by `scripts/build-dict.mjs` from two MIT-licensed sources:
  - [complete-hsk-vocabulary](https://github.com/drkameleon/complete-hsk-vocabulary): 11,368 HSK words with levels, pinyin, CC-CEDICT meanings and measure words
  - [ECDICT](https://github.com/skywind3000/ECDICT): an English → Chinese dictionary that lists translations by part of speech, most common sense first (water: *n.* 水; *v.* 浇水)

  An English word maps to an HSK word when ECDICT lists it for that part of speech, ideally confirmed by the HSK word's own CC-CEDICT gloss. CC-CEDICT can add a word only if this English word is the Chinese word's main meaning and ECDICT doesn't contradict it. If the best translation is above your level, the matcher falls back only to close synonyms (冷 for "cold" instead of 寒冷). Otherwise it leaves the word in English: "plant" never becomes 工厂 (a factory). `scripts/overrides.mjs` holds the remaining hand fixes, per part of speech if needed (`show:n` → 节目).
- **Grammar** – the Chinese has to read correctly wherever Chinese words meet:
  - question words keep Chinese order: "How do I use AI?" → 我 怎么 用 AI?
  - numbers get the noun's measure word: three books → 三本 书, two cats → 两只 猫
  - possessives get 的: my friend → 我的 朋友, people's → 人的
  - comparatives and superlatives get 更/最: cheaper → 更便宜, highest → 最高
  - they/them/their follow what they refer to: 他们 for people, 它们 for animals and things ("when cats walk, they…" → 它们). They stay English when the referent isn't in the paragraph
  - time words are swapped only where Chinese would put them: "Today I eat rice" → 今天 …, but "I eat rice today" keeps *today*
  - parts of phrasal verbs, hyphenated compounds (full-time), names and grammar words (the, can, like, …) stay English
- **Page** – `src/content.js` walks the page's text nodes in idle-time slices and tags each paragraph once. It skips inputs, editors, code, buttons and `translate="no"` content, and stops at 400 replacements per page. A MutationObserver handles content that loads later. Pages whose `<html lang>` is set to something other than English are left alone.

## Development

```sh
npm test                 # unit tests for the matcher and dictionary (node:test, no dependencies)
npm run build:dict       # regenerate src/dict.js (downloads complete.json and the 66 MB ecdict.csv)
node scripts/build-dict.mjs complete.json ecdict.csv   # ...or from local copies
NO_OVERRIDES=1 npm run build:dict                      # see the output without overrides.mjs
npm run icons            # regenerate icons/ (needs Python + Pillow and Noto Sans CJK)
npm run pack             # zip for the Chrome Web Store
```

After editing files, click the reload button on the extension in `chrome://extensions` and refresh the tab.

## Known limitations

- The tagger tells parts of speech apart, but not senses within one part of speech: "restrictions were lifted" still gets 提高 (raise) instead of 解除 (remove). Add a fix to `scripts/overrides.mjs` and rebuild.
- English word order is kept outside the rules above, so the result is English with Chinese words in it, not Chinese sentences.
- Pronunciation needs a Chinese voice. Chrome on Windows, macOS and ChromeOS includes one; on Linux you may need to install one (for example through speech-dispatcher).
